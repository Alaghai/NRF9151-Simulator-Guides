# nRF9151 simulator guides

Deploy or replace the DigitalOcean TCP listener using the [Micro V8 server README](micro-tcp-server/README.md) and the [Word deployment guide](micro-tcp-server/Micro%20TCP%20Server%20V8%20Deployment%20Guide.docx). They cover the current endpoint setup, systemd service, per-IMEI settings queue, and message history.

The [simulator bundle](Micro_Simulator_Dual_Transport_Complete_v6) contains the firmware, Windows relay, and protocol documents. For deployment commands, paths, and the new Droplet address, use the current server guide linked above.
